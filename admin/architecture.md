# Архитектура системы

## Компоненты

### Controller
Центральный сервер, который:
- Принимает конфиги от admin client 
- Хранит глобальные правила и правила для фильтров
- По запросу воркера формирует политику (глобальные правила + правила конкретного фильтра)
- Собирает статистику от воркеров

### Worker 
Обработчик трафика:
- Периодически запрашивает политику (GetPolicy)
- Классифицирует домены (Classify)
- Отправляет статистику (SendStats)

### Admin Client 
Управление конфигурацией:
- Загружает TOML-файл с правилами
- Проверяет базовую валидность 
- Отправляет конфиг на контроллер
